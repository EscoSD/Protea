# 🛠️ Protea - Bot de Discord para OLA BBS

**Protea** es un bot desarrollado especialmente para el servidor **OLA BBS**. Ofrece funcionalidades para registrar actividad en canales de voz, generar rankings y conversar mediante un modelo de lenguaje integrado.

---

## ✨ Funcionalidades

- 🎙️ Registro del **tiempo pasado en canales de voz** del servidor para cada usuario.
- 🏆 Visualización de un **ranking** con los **5 usuarios más activos** en canales de voz.
- 🤖 Integración con un **modelo de lenguaje** para mantener conversaciones fluidas con el bot.

---

## 📜 Comandos Disponibles

| Comando       | Descripción                                                                 |
|---------------|-----------------------------------------------------------------------------|
| `¿help`       | Muestra los comandos disponibles en **Protea**.                             |
| `¿vcTime`     | Muestra el **tiempo total** que has pasado en canales de voz. <br>📅 *Desde el 15-09-2024 a las 14:53:52*. |
| `¿vcRanking`  | Muestra el **ranking** de los 5 usuarios con más tiempo en canales de voz. <br>📅 *Desde el 15-09-2024 a las 14:53:52*. |
| `¿catMe`      | 🐱 Invoca un gato.                                                          |
| `¿dogMe`      | 🐶 Invoca un perro.                                                         |
| `¿carteles`   | 🐷 Invoca un cerdo.                                                         |
